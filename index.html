Firebase App

La nevera de casa

Aplicación web colaborativa para la organización del hogar: gestión de lista de la compra en tiempo real e historial inteligente de comidas.

¿Qué es y cómo se usa?
  • La compra: Selecciona tu perfil familiar para añadir productos. Marcar con tick los mueve a "Ya comprado" (reutilizables para la siguiente semana) o elíminalos con "X".
  • Qué comer: Registra tus platos habituales. Al pulsar "Hecho hoy", inicia un contador de días. Ordena automáticamente las comidas pasadas: alerta naranja a los +5 días y roja a los +10 días para no repetir menú.
Desarrollo y Costes: Desarrollado en HTML5, JavaScript Vanilla y CSS. Sincronización en tiempo real con Firebase Realtime Database. Coste de infraestructura: 0€ (uso del plan gratuito de Firebase y hosting en GitHub Pages).
Uso de IA, Ajustes y Seguridad: Diseño e interfaz estructurados con asistencia de IA. Se ajustaron manualmente la lógica del contador de días y la reactividad de Firebase. En cuanto a seguridad, se configuraron reglas de autenticación e inocuidad de datos en la consola de Firebase para evitar lecturas/escrituras no autorizadas en la base de datos.
